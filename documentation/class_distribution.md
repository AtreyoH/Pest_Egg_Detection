# Class Distribution

This dataset is formatted for single-class object detection. The target class represents the distinct pink egg masses of the Golden Apple Snail (*Pomacea canaliculata*)[cite: 20].

| Class ID | Class Name | Description |
|---|---|---|
| `0` | `egg` | Microscopic Pomacea canaliculata egg masses on agricultural foliage[cite: 23, 24]. |

**Total Images:** 10,592[cite: 24]
**Training Set:** 8,473 images[cite: 24]
**Validation Set:** 2,119 images (containing 4,850 individual bounding box instances)[cite: 24]
**Relative Target Scale:** ≤ 10% of total spatial dimensions (0.0-0.1)[cite: 23, 24]
